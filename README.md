
# 🏆 우선픽 AI Agent

## 1. 프로젝트 소개
통신 매장의 운영 데이터를 분석하여 매장별 상태를 파악하고, 관리가 필요한 매장의 우선순위를 추천하는 AI Agent 프로젝트입니다.

## 2. 프로젝트 목표
- 매장별 판매 실적 및 운영 데이터 분석
- 매장별 현황 비교 및 관리 우선순위 판단
- AI Agent를 활용한 분석 결과 제공
- 매장 관리자의 의사결정 지원

## 3. 주요 수행 내용
- 매장 상태 판단 로직 설계
- 프로젝트 데이터 정리 및 분석
- AI Agent 프롬프트 설계
- 분석 결과 연계 및 검증

## 4. 담당 역할
프로젝트에서 매장 상태 판단 로직 설계, 데이터 정리, AI 프롬프트 설계 및 분석 결과 검증을 담당했습니다.

## 5. 활용 기술 및 도구
- Python
- AI Agent 및 LLM
- 데이터 분석 및 처리
- n8n
- Google Sheets

## 6. 프로젝트 성과
🏆 KT K-뉴딜 경진대회 대상 수상

## 7. 프로젝트 결과
KT K-뉴딜 경진대회에서 대상을 수상했으며, 매장 운영 데이터 분석과 AI Agent를 활용한 관리 우선순위 추천 아이디어를 제안하고 프로젝트를 수행했습니다.
